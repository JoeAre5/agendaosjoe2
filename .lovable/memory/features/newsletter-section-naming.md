Admin menu section housing blog/headlines management:
- ES label: **Boletín**
- EN label: **Newsletter**

Reason: "Contenido" was rejected — too ambiguous because content is also created in Push Notifications (broadcasts) and other places. "Boletín" is the standard PR/LatAm translation for newsletter.

Inside the section (Phase 3): **Titulares** / **Headlines** (the blog post manager).

Broadcast composer stays in the existing Notifications page — do NOT move it under Boletín/Newsletter.
